## 🏗️ Framework Explanation

### What This Code Does

Your resume is a **Single-Page Application (SPA)** built with React. It:

1. **Renders dynamically** - Components update without page reload
2. **Manages state** - Dark mode toggle stored in memory
3. **Handles printing** - Converts to PDF with custom styling
4. **Responds to screen size** - Mobile-first design

### The Three Technologies

#### 1. React (UI Framework)
```jsx
// React code: Declarative UI
const [darkMode, setDarkMode] = useState(false);  // State hook

return (
  <div className={darkMode ? 'bg-dark' : 'bg-light'}>
    Content...
  </div>
);
// When darkMode changes, component re-renders automatically
```

**Why React?**
- Reusable components (DRY)
- Efficient re-renders (virtual DOM)
- Large ecosystem
- Hot reload in development

#### 2. Vite (Build Tool)
```
Your Source Code (src/)
        ↓
Vite processes:
- Compiles JSX → JavaScript
- Bundles modules
- Processes Tailwind CSS
- Optimizes assets
        ↓
Output: dist/ (3 files ready for production)
```

**Why Vite?**
- 10x faster than Webpack (uses esbuild)
- Minimal configuration
- Excellent DX (Developer Experience)
- Perfect for SPA apps

#### 3. Tailwind CSS (Styling)
```jsx
// Instead of writing CSS:
className="min-h-screen bg-gray-50 text-gray-900 transition-colors"
// Tailwind generates: min-height: 100vh; background: #f9fafb; etc.
```

**Why Tailwind?**
- Utility-first approach (no CSS files to maintain)
- Dark mode built-in
- Responsive classes
- Tiny final bundle (tree-shaking removes unused utilities)

#### 4. lucide-react (Icons)
```jsx
import { Moon, Sun, Printer } from 'lucide-react';

<Moon size={20} />  // SVG icon, tree-shaken if unused
```

**Why lucide-react?**
- Modern, beautiful icons
- Only used icons bundled (tree-shaking)
- Lightweight SVGs
- Perfect with React

## 🏗️ Building for Production

### What "Build" Means

```
src/App.jsx (React component)
src/main.jsx (entry point)
node_modules/react (library)
Tailwind config
        ↓
Vite build process:
  1. Compile JSX → JavaScript
  2. Bundle modules → single JS file
  3. Process Tailwind → final CSS
  4. Minify (remove whitespace)
  5. Add hashes for cache-busting
        ↓
dist/ (production files - ready to upload!)
```

### Build Steps

#### 1. Build
```bash
npm run build
```

**Output:**

## 🌐 Deploying to PHP/Apache Hosting

### Hosting Options

| Provider | Cost | Setup |
|----------|------|-------|
| GoDaddy | $2.99/mo | cPanel |
| Bluehost | $2.95/mo | cPanel |
| HostGator | $2.75/mo | cPanel |
| Namecheap | $1.99/mo | cPanel |

### Step-by-Step Deployment

#### Option A: Using cPanel (Easiest)

**1. Build locally**
```bash
npm run build
```

**2. Log into cPanel**
- Visit: `https://cpanel.your-domain.com` or `https://your-domain.com:2083`
- Username: Your cPanel username
- Password: Your password

**3. Open File Manager**
- cPanel Dashboard → Files → File Manager

**4. Navigate to public_html**
- Should be in `public_html` folder already
- This is your website root

**5. Upload Files**
- Click "Upload"
- Drag & drop from your `dist/` folder:
  ```
  dist/index.html        → Upload to public_html/
  dist/assets/           → Upload entire folder
  ```

**6. Verify Upload**
- Files should appear in public_html
- Visit: `https://your-domain.com`
- 🎉 Your resume is live!

#### Option B: Using FTP (More Control)

**1. Download FTP Client**
- FileZilla: https://filezilla-project.org/
- WinSCP: https://winscp.net/

**2. Get FTP Credentials**
- Log into cPanel
- Account Information → FTP Accounts
- Note: Host, Username, Password, Port (usually 21)

**3. Connect**
- Open FileZilla
- Host: `your-domain.com`
- Username: Your FTP username
- Password: Your FTP password
- Port: 21 (or 22 for SFTP)
- Click "Quickconnect"

**4. Navigate to public_html**
- Right panel: Open `public_html` folder

**5. Upload Files**
- Left panel: Navigate to your `dist/` folder
- Drag `index.html` and `assets/` to right panel
- Wait for upload to complete

**6. Visit Your Domain**
- Open: `https://your-domain.com`
- Done! ✅

#### Option C: Using SSH (Advanced)

If your host supports SSH:

```bash
# On your PC (in rman-resume folder)
scp -r dist/* your-username@your-domain.com:~/public_html/
```

### (Optional) Add .htaccess for Routing

Create `public_html/.htaccess`:

```apache
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  
  # Don't rewrite if it's a real file or directory
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  
  # Rewrite everything to index.html (for SPA routing)
  RewriteRule . /index.html [L]
</IfModule>
```

**Via cPanel:**
1. File Manager → public_html
2. Right-click → Create new file → Name: `.htaccess`
3. Edit → Paste above content → Save

## 🐛 Troubleshooting

### Development Issues

#### "npm: command not found"
**Problem:** Node.js not installed  
**Solution:** Install from https://nodejs.org/

#### Port 5173 already in use
**Problem:** Another app using same port  
**Solution:**
```bash
npm run dev -- --port 5174
```

#### Changes not showing in browser
**Problem:** Hot reload not working  
**Solution:**
```bash
# Stop server (Ctrl+C)
# Clear browser cache (Ctrl+Shift+Delete)
# npm run dev
```

#### `Cannot find module 'react'`
**Problem:** Dependencies not installed  
**Solution:**
```bash
npm install
```

### Build Issues

#### Build fails - "module is not defined"
**Problem:** PostCSS config issue  
**Solution:** Already fixed in your setup ✅

#### "dist folder not created"
**Problem:** Build failed silently  
**Solution:**
```bash
npm run build          # Check output for errors
npm install terser     # Install if missing
npm run build          # Try again
```

### Deployment Issues

#### Blank page on hosting
**Problem:** Files not in correct folder  
**Solution:** Ensure files are in `public_html`, not subdirectory

#### 404 error on refresh
**Problem:** Routing not configured  
**Solution:** Add `.htaccess` file (see deployment section)

#### Dark mode not working on host
**Problem:** JavaScript not loading  
**Solution:**
```bash
# Check browser DevTools (F12)
# Look for errors in Console tab
# Clear browser cache and retry
```

#### Print not working
**Problem:** Browser issue  
**Solution:** Use Chrome or Firefox latest version
